# Module 2: The Digital Twin (Gazebo & Unity)

Simulation is used to test robots in a digital world before using real hardware.

## What is Gazebo?
Gazebo is a robot simulator that provides physics, gravity, and collision detection.

## Physics Simulation
It simulates real-world behavior like:
- Gravity
- Friction
- Object collisions

## Sensor Simulation
Gazebo can simulate:
- Cameras
- LiDAR
- IMU (motion sensors)

## What is Unity?
Unity is used for high-quality visualization and human-robot interaction.

## Why Simulation is Important
- Safe testing
- No hardware damage
- Faster development
- Low cost
