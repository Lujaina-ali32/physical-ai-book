# Module 4: Vision, Language & Action (VLA)

This module connects AI language models with robots.

## Speech Recognition
OpenAI Whisper is used to convert voice into text.

## Language Understanding
Large Language Models (LLMs) convert human commands into robot instructions.

Example:
"Clean the room" → Move, scan, pick, place

## Vision System
Robots use cameras to:
- Detect objects
- Measure distance
- Understand surroundings

## Action Execution
Robots perform actions using motors and joints after understanding commands.

## Why VLA is Important
- Makes robots intelligent
- Human-like behavior
- Voice-controlled robots
