# Sensors in Physical AI

Robots ke paas alag alag sensors hote hain:

- **LiDAR:** Distance measure karta hai, environment ka 3D map banata hai  
- **Cameras:** Color aur depth data provide karte hain  
- **IMU:** Balance aur motion detect karta hai  
- **Force/Torque Sensors:** Object pakadne ki strength measure karte hain  

Sensors robot ko apne aas paas ki duniya samajhne mein madad karte hain.
