# Capstone Project: The Autonomous Humanoid Robot

In this project, students build a complete intelligent humanoid system.

## Project Goal
The robot should:
- Listen to voice commands
- Plan actions using AI
- Navigate obstacles
- Identify objects
- Pick and place objects

## Technologies Used
- ROS 2
- Gazebo
- NVIDIA Isaac
- OpenAI Whisper
- Vision-Language-Action system

## Example Workflow
1. User gives voice command
2. Robot processes command using AI
3. Robot plans path
4. Robot moves and performs task

## Learning Outcome
By the end of this project, students understand:
- Physical AI
- Humanoid robotics
- Conversational robots
