# Module 3: The AI-Robot Brain (NVIDIA Isaac)

NVIDIA Isaac is a powerful platform for building AI-powered robots.

## Isaac Sim
Isaac Sim is a photorealistic simulator used for:
- Training robots
- Creating synthetic data
- Testing navigation

## Visual SLAM
SLAM means Simultaneous Localization and Mapping.
It helps the robot understand where it is and map the environment.

## Navigation System (Nav2)
Used for:
- Path planning
- Obstacle avoidance
- Robot movement

## Sim-to-Real Transfer
Training is done in simulation and then moved to a real robot.

## Why Isaac is Important
- High performance AI
- GPU acceleration
- Real-world deployment support
