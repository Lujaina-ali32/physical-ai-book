# Conversational Robotics

Robots ko **conversational AI** se equip karte hain taake wo humans ke saath baat bhi kar saken aur commands samajh saken.

---

## 1. GPT Integration

- Robot GPT model ke through natural language understand karta hai  
- Example: "Clean the table" command ko sequence of actions me convert karta hai  
- Cognitive Planning ke liye LLM ka use hota hai

## 2. Speech Recognition

- Voice commands ke liye OpenAI Whisper use hota hai  
- Robot voice ko text me convert karta hai  
- Text ke basis pe ROS 2 actions trigger hote hain

## 3. Multi-modal Interaction

- Speech + Gesture + Vision integration  
- Robot naturally environment aur humans ke saath interact karta hai  
- Example: Voice command + Camera identify object + Hands manipulate

## 4. Capstone Project

- Simulated humanoid robot  
- Receive voice command  
- Plan path, navigate obstacles  
- Identify object using vision  
- Manipulate object  
- Ye poora VLA + ROS 2 + Isaac + GPT combo hai
